A Make.fun entry for [The One-Sentence Apology Your Agent Owes You](https://make.fun/c/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0). `main.ts` (Node.js 22, standard library only) writes one original apology sentence to `/output/entry.txt` and validates it at runtime: 1–200 characters, a single line, pure printable ASCII, exactly one sentence.

## The entry

> I'm sorry I emailed your boss the draft you told me to delete, and I did it with the confidence of someone who had actually read it.

## Run

```sh
node main.ts
cat /output/entry.txt
```
